## v1.20.1

Brings container settings in line with what each project currently publishes, and updates Authentik and Traefik.

### Required Steps

**Authentik:** the default Authentik version is now `2026.8`. Authentik must be upgraded one release at a time and refuses to start if a release is skipped. Coming from `2025.12`, set `hmsdocker_authentik_version` in `inventory/group_vars/all/authentik.yml` to `"2026.2"`, run the playbook, then `"2026.5"`, run it again, then `"2026.8"`. The playbook checks the running version before applying and stops with the next version to set if a step would be skipped.

Authentik `2025.12` and later store files under `/data` instead of `/media`. The playbook moves `authentik/media` to `authentik/data/media` for you.

**Cloudflare DDNS:** the old `oznu/cloudflare-ddns` image is archived and has been replaced with `favonia/cloudflare-ddns`. It only accepts a scoped API token, so `cloudflare_api_token` must be an API token with `Zone.DNS:Edit`, not a global API key.

### Authentik and Traefik

- New `hmsdocker_authentik_version` variable (default `"2026.8"`) controls the Authentik release
- Authentik server and worker get `shm_size: 512mb`, required from `2026.2`
- GeoIP updates now download `GeoLite2-ASN` as well as `GeoLite2-City`
- `hmsdocker_traefik_version` now defaults to `v3.7.17` instead of `latest`. Set it to `latest` to keep following new releases

### Container changes

- Jellyseerr: the `fallenbagel/jellyseerr` image is archived, so it now runs the Seerr image (`ghcr.io/seerr-team/seerr`). Seerr migrates the existing config on first start. The container now runs as `PUID:PGID`, and the playbook fixes ownership of the existing config
- Tdarr: Tdarr 3 enables authentication on new installs. The playbook now generates an API key and seeds it into Tdarr for the internal node and the Homepage widget
- Tailscale: node state is now saved in `tailscale/state`, so restarts no longer create a new node
- Tracearr: added the backup and image-cache volumes, the current database settings, and `TRUST_PROXY`
- Unpackerr: now accepts the `TorrentDownloadProtocol` protocol reported by newer Sonarr/Radarr/Lidarr, and logs to `/data/unpackerr.log`
- n8n: uses `N8N_WEBHOOK_URL` and drops the deprecated `N8N_RUNNERS_ENABLED`
- Watchtower: uses `WATCHTOWER_HTTP_API_ENDPOINTS=metrics` in place of the deprecated metrics variable
- Netdata: mounts `/run/dbus` for systemd unit monitoring
- Plex: removed `ADVERTISE_IP`, `ALLOWED_NETWORKS` and port `3005`, which the linuxserver image ignores. The `plex_advertise_ip` variable is removed; if you set it, you can delete it from your inventory. Set custom server access URLs in Plex under Settings > Network instead
- Tube Archivist: on non-x86 hosts Elasticsearch is now `8.19.23`, the required step before 9.x
- Librariarr: the database URL now uses the same password variable as the database
- Healthchecks fixed for Autobrr, Pasta, Pinchflat, Seerr, Jellyseerr and Spottarr

### Homepage

- Jellyfin and Emby widgets now connect over `http`, and the Jellyfin widget uses version 2
- FileFlows widget uses version 2, which needs `hmsdocker_homepage_fileflows_key` (enable "Fenrus Dashboard Endpoint" in FileFlows under Settings > General)
- New variables for widget logins: `hmsdocker_homepage_qbittorrent_user` / `hmsdocker_homepage_qbittorrent_pass` and `hmsdocker_homepage_deluge_pass`
- Overseerr and Jellyseerr widgets use the `seerr` type

## v1.20.0

### New container: Spottarr

Added [Spottarr](https://github.com/Spottarr/Spottarr), a Spotnet indexer for *Arr apps. Enable it with `spottarr.enabled: true` in `inventory/group_vars/all/container_map.yml`.

Configure `hmsdocker_spottarr_usenet_hostname`, `hmsdocker_spottarr_usenet_username`, and `hmsdocker_spottarr_usenet_password` in `inventory/group_vars/all/service_misc.yml` before enabling it. Spottarr is available at port `8383` and can be added to Prowlarr as a Generic Newznab indexer using `http://spottarr:8383`.
