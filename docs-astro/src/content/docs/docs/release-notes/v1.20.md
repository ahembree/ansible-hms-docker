## v1.20.0

### New container: Spottarr

Added [Spottarr](https://github.com/Spottarr/Spottarr), a Spotnet indexer for *Arr apps. Enable it with `spottarr.enabled: true` in `inventory/group_vars/all/container_map.yml`.

Configure `hmsdocker_spottarr_usenet_hostname`, `hmsdocker_spottarr_usenet_username`, and `hmsdocker_spottarr_usenet_password` in `inventory/group_vars/all/service_misc.yml` before enabling it. Spottarr is available at port `8383` and can be added to Prowlarr as a Generic Newznab indexer using `http://spottarr:8383`.
