## v1.21.0

### New Containers

- [Pocket ID](https://github.com/pocket-id/pocket-id): passkey-only OIDC provider. The encryption key is generated automatically on first run and stored in the Pocket ID config directory.
- [Tinyauth](https://github.com/steveiliop56/tinyauth): lightweight authentication middleware for Traefik. Add users with `hmsdocker_tinyauth_users` in `inventory/group_vars/all/service_misc.yml` (`username:bcrypt_hash` entries). To protect another service, add `tinyauth-<project name>@docker` to that service's Traefik router middlewares.

Both are disabled by default. Enable them in `inventory/group_vars/all/container_map.yml`.
