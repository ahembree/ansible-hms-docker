:::tip[Tip]

Ports are _NOT_ exposed by default (with the exception of the reverse proxy, Traefik or [Caddy](/docs/services/caddy/), `80/443`) on the host.

:::

The service ports (such as for Sonarr (`8989`) or Radarr (`7878`)) will be **exposed/open** on the host machine if:

* `expose_ports` is set to `true` for the specific container in `inventory/group_vars/all/container_map.yml`

* Neither Traefik nor Caddy is enabled

* `proxy` is set to `false` on that specific container in `inventory/group_vars/all/container_map.yml`

See the **[Container Map](/docs/container-list/#container-map)** for the `Host Port` value for each service as there may be overlapping default ports, meaning the default port may have changed for a service.
