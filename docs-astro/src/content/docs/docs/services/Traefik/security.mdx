## How the containers are protected

By default, Traefik is configured with an allowlist that only permits private IPs (RFC1918) to access containers.

**Exception:** If you route a container through [Cloudflare Tunnel](/docs/services/cloudflare/tunnel/), the traffic goes directly to the container and bypasses Traefik entirely. Traefik allowlists and middlewares do not apply to Tunnel traffic.

**IPv6:** The project's Docker network is IPv4-only, so Docker forwards IPv6 connections to Traefik through its userland proxy, and Traefik sees the Docker network's gateway, a private address, as the client. The private allowlist therefore lets every IPv6 client through. If the server has a public IPv6 address (for example with `cloudflare_ddns_create_ipv6_aaaa_record` enabled), block incoming IPv6 traffic to ports `80` and `443` on your router or firewall unless every app reachable that way is meant to be public.

This is controlled on a per-container basis in the `inventory/group_vars/all/container_map.yml` file as the `expose_to_public` variable for each container. If you set this to `true`, it will allow all IPs (`0.0.0.0/0`) to access them.

## Proxies in front of Traefik

If another proxy sits in front of Traefik, such as a load balancer, Traefik sees that proxy's IP as the client IP. To log the real client IP instead, add the proxy's IP or subnet to `hmsdocker_proxy_trusted_proxies` in `inventory/group_vars/all/reverse_proxy.yml` (`traefik.yml` on installs from before these settings were renamed):

```yaml
hmsdocker_proxy_trusted_proxies:
  - 192.168.1.10
```

Traefik then keeps the `X-Forwarded-For` header sent by these proxies on the `web` and `websecure` entrypoints (ports `80` and `443`) and logs the client IP from it. [CrowdSec](/docs/services/crowdsec/) uses the same list. The allowlists above still check the IP that connects to Traefik.

Traefik logs that header exactly as received, so the proxy must set it to the client's IP only, replacing any value the client sent (for example `proxy_set_header X-Forwarded-For $remote_addr;` in nginx, or `http-request set-header X-Forwarded-For %[src]` in HAProxy). A proxy that adds the client's IP to an existing header lets clients put any IP they like in Traefik's access log.

Only list proxies you control. Any client in these ranges can set its own `X-Forwarded-For` header.

## Security Hardening

There is a `hmsdocker_proxy_security_hardening` variable in `inventory/group_vars/all/reverse_proxy.yml` (`traefik.yml` on installs from before these settings were renamed) that will do the following if enabled:

- Enforce HTTPS only requests
- Enforce Traefik dashboard over secure connection
- Disable port `8080` access to Traefik
  - This will also disable Homepage integration with Traefik
- Only allows requests to services/Hosts with Traefik enabled
- Disable TLS1.0 and TLS1.1 and use TLS1.2 as the new minimum
- Add security headers for the following:
  - `X-Frame-Options: DENY` : [[Mozilla Docs](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/X-Frame-Options)] Denies iFrame embedding
  - `X-Content-Type-Options: nosniff` : [[Mozilla Docs](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/X-Content-Type-Options)] Blocks a request if the request destination is of type style and the MIME type is not text/css, or of type script and the MIME type is not a [JavaScript MIME type](https://html.spec.whatwg.org/multipage/infrastructure.html#javascript-mime-type)

## Middlewares

The following middlewares are available:

- `internal-secured`: A chain, applies the `internal-ipallowlist`, `https-only`, `secure-headers`
- `external-secured`: A chain, applies the `external-ipallowlist`, `https-only`, `secure-headers`
- `internal-ipallowlist`: Allows only RFC1918 private address space and any other IPs/ranges defined in the `hmsdocker_proxy_allow_list` variable
- `external-ipallowlist`: Allows all traffic from `0.0.0.0/0`
- `https-only`: Configures permanent redirection to HTTPS
- `secure-headers`: Applies headers to prevent iFrame embedding, blocks requests if MIME types do not match certain criteria, and only allows Host headers for applications that are enabled within this project
